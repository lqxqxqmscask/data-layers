## Overview

Data Layers is a Stardew Valley SMAPI mod that overlays hidden game data directly on the game world as color-coded visual maps — irrigation coverage, scarecrow range, bee house flower range, Junimo hut harvest range, and more. It removes the need for mental radius calculations and makes efficient farm layout planning visual and immediate.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Data Layers** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Irrigation Map** | Shows which tiles are watered versus dry at a glance |
| **Scarecrow Range** | Color overlay displays the exact protection radius of each scarecrow |
| **Bee House Flowers** | Highlights which flowers are within range of each bee house |
| **Junimo Coverage** | Displays harvest range for each Junimo hut on the farm |
